## 📌 Sobre o Projeto

O **Dominus** é um sistema de cardápio digital desenvolvido para funcionar em tablets, inspirado em plataformas como o **Goomer**. O projeto permite que clientes de restaurantes visualizem o cardápio, personalizem seus pedidos e os enviem diretamente pela tela.

> ⚠️ **Este projeto está em desenvolvimento ativo.** Funcionalidades estão sendo implementadas progressivamente.

---

## 🤖 Desenvolvido com Auxílio de IA

Este projeto está sendo construído com o apoio de ferramentas de Inteligência Artificial (como Claude). O objetivo é aprender **React** e **JavaScript** na prática, utilizando a IA para entender conceitos, tirar dúvidas e evoluir o código com autonomia — não apenas copiar soluções prontas.

> 💡 Acredito que aprender com IA de forma consciente é uma habilidade essencial para o desenvolvedor moderno.

## ✅ Funcionalidades Implementadas

- [x] Header com nome do restaurante
- [x] Sidebar de navegação por categorias
- [x] Cards de produtos com imagem, nome e preço
- [x] Modal de produto com seletor de quantidade e campo de observações
- [x] Painel de carrinho com slide-in animation
- [x] Navegação por scroll com IntersectionObserver (estilo iFood/Goomer)
- [x] Suporte a adicionais no modal do produto

## 🚀 Como Rodar Localmente

```bash
# Clone o repositório
git clone https://github.com/veronez22/Dominus.git

# Acesse a pasta do projeto
cd Dominus

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` no navegador.
